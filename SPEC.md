# Как должно работать: DevSpaces

> Требования пользователя. Меняются только после его подтверждения.
> Последнее подтверждение: 2026-10-19, пользователь, в переписке с Claude Code.
> Пометки: [Требование] — пользователь сказал сам; [Решение] — предложено и принято; [Предположение] — наше, не подтверждено; [Вопрос] — решения нет.

## Что делает программа

Лёгкая панель у правого края основного монитора Windows 11. На ней карточки всех виртуальных рабочих столов: название, миниатюра, список открытых приложений. Клик по карточке переключает настоящий рабочий стол Windows. Панель не мешает работе: не появляется в Alt+Tab, не забирает фокус, не попадает на снимки экрана и прячется, когда мешает активному окну.

## Словарь

| Термин | Значение |
|---|---|
| Стол | Виртуальный рабочий стол Windows (Win+Tab). Имя — как в Windows; без имени — «Рабочий стол N». |
| Карточка | Плитка стола на панели. |
| Активный стол | Стол, который сейчас на экране. Его карточка — в зелёной рамке. |
| Ручка | Тонкая полоска у правого края основного экрана; наведение на неё открывает спрятанную панель. |
| Окно с фокусом | Окно, в котором сейчас работает пользователь (`GetForegroundWindow`). |

## Панель и карточки

- [Требование] Панель у правого края **основного** монитора, по центру по высоте, высота — по числу карточек. Ширина окна 124 px, миниатюра 84 px (логические px; при масштабе 125 % — 105 физических) [Требование 2026-10-20: «в 2 раза меньше»]. Подписи: название 8 pt, приложения 6,5 pt.
- [Требование] Подложки у панели нет: карточки лежат прямо на рабочем столе. Под подписью — узкая тёмная плашка по ширине текста (иначе текст теряется на иконках).
- [Требование] Перспектива: карточка повёрнута на 22°, **левый край меньше и уходит вглубь, правый больше**.
- [Требование] Наведение: за 0,16 с карточка увеличивается на 7 % и разворачивается вдвое меньше (11°). Уход курсора — обратно.
- Карточка: миниатюра со скруглением, ниже название стола и приложения через « · » (до ширины, дальше «…»); нет окон — «Нет окон». Активный стол — зелёная рамка `#34C759`.
- Список столов, имена и активный стол обновляются сами (стол создали/удалили/переименовали в Windows — карточки меняются за ~1 с).
- Клик по карточке — переход на этот стол; клик по активной — ничего.

## Режимы показа (трей → один из трёх)

| Режим | Поведение |
|---|---|
| **Всегда показывать** | Панель видна всегда, ручки нет. |
| **Скрывать, если мешает окну** (по умолчанию) [Требование] | Окно с фокусом заходит на область панели (пересечение больше 16×16 физических px) — панель уезжает, появляется ручка. Окно больше не мешает — панель возвращается сама. Смена состояния — после 0,2 с без изменений (чтобы не дёргалась, пока окно тащат). |
| **Скрывать всегда** | Панель видна только после наведения на ручку или край. |

- Не считаются окном, которое мешает: рабочий стол (`Progman`, `WorkerW`, например после Win+D) — панель показывается; окна самой DevSpaces, панель задач, Alt+Tab, «Пуск», область уведомлений — состояние не меняется; свёрнутые и скрытые окна — не мешают.
- **Открыть спрятанную панель:** задержать курсор 0,2 с на ручке (зона 12×180 px по центру правого края) или на последних 2 px правого края основного экрана; кнопка мыши не должна быть зажата (чтобы не срабатывать при перетаскивании скроллбара VS Code); верхние и нижние 60 px края не считаются (там «закрыть окно» и «свернуть всё»).
- **Закрыть открытую поверх окна панель:** курсор вне панели (с запасом 6 px) дольше 0,35 с.
- Второй монитор справа не открывает панель и не вызывает мигания (был баг). Анимация выезда при соседнем мониторе справа сдвигает панель на 4 px, иначе на 40 px — чтобы не заезжать на соседний экран.
- Левый клик по значку в трее — показать панель на 2,5 с.

## Миниатюры

- Снимки только в **оперативной памяти**; после перезапуска набираются заново. [Требование]
- Сама панель и ручка на снимки не попадают (исключены из захвата экрана).
- **Активный стол** — настоящий скриншот основного монитора раз в 1 с. После переключения стола 0,8 с снимки не делаются (на экране анимация), снимок, начатый до переключения, выбрасывается.
- **Перед переходом по клику** на карточку — сразу снимок текущего стола, потом переключение. [Требование] При переключении горячими клавишами Windows снимок не старше 1 с.
- **Неактивные столы** — раз в 60 с, **только пока панель видна**, картинка собирается: обои Windows → окна этого стола снизу вверх (каждое окно рисует себя через `PrintWindow`) → панель задач с текущего экрана. Первая сборка ~5 с после запуска, поэтому карточек «Нет снимка» после старта нет. [Требование]
  - Ограничения: нет иконок рабочего стола; если на столах разные обои — везде текущие; окна, которые не умеют рисовать себя (видео, игры, защищённые), выйдут чёрными.
- Если пользователь перешёл на стол, пока для него собиралась картинка, — собранная выбрасывается (настоящий снимок точнее).

## Список приложений на карточке

- Окна стола, которые есть в Alt+Tab, кроме закреплённых на всех столах и самой DevSpaces; без повторов, в порядке наложения.
- Имя — по exe с понятными заменами (`code` → «VS Code», `explorer` → «Проводник», `msedge` → «Edge» и т. д.); `WhatsApp.Root` → «WhatsApp»; UWP-окна (`ApplicationFrameHost`) — по заголовку.

## Трей и настройки

- Меню: три режима (один выбран), «Автозапуск» (галочка), «Выход».
- Автозапуск — ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DevSpaces`: путь к EXE (или `pythonw devspaces.py` при запуске из исходников).
- `%APPDATA%\DevSpaces\settings.json`: `{"mode": "smart" | "always" | "auto", "autostart": bool}`. Старый ключ `pinned` при чтении удаляется, режим без значения — `smart`.
- Второй экземпляр программы не запускается.

## Не входит в первую версию

- Сохранение снимков на диск между запусками (противоречит «только в памяти»; решает пользователь).
- Резерв полосы справа, чтобы развёрнутые окна не заходили под панель (AppBar) — заменено умным скрытием. [Решение]
- Создание, удаление, переименование столов с панели; иконки приложений; горячая клавиша; перетаскивание окна на карточку.
- Панель на неосновном мониторе.
