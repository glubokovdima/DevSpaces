# DevSpaces

Лёгкая боковая панель для Windows 11 в духе Stage Manager на macOS: карточки виртуальных рабочих столов с миниатюрами и списком открытых приложений. Клик по карточке — переход на этот стол.

*A Stage Manager-like sidebar for Windows 11 virtual desktops (Python, PySide6, pyvda).*

## Возможности

- Карточки всех виртуальных рабочих столов Windows: название, миниатюра, открытые приложения; активный стол — в зелёной рамке.
- Переключение настоящих рабочих столов Windows по клику.
- Карточки с перспективой и плавным увеличением при наведении, без лишних элементов.
- Миниатюры: активный стол — раз в секунду, неактивные — раз в минуту (окна стола рисуются через `PrintWindow`), всё только в памяти.
- Панель видна на всех рабочих столах, не появляется в Alt+Tab, не забирает фокус и не попадает на скриншоты.
- Три режима в трее:
  - **Всегда показывать**;
  - **Скрывать, если мешает окну** — панель уезжает, когда активное окно заходит на её место, и возвращается сама;
  - **Скрывать всегда** — панель открывается наведением на полоску у правого края.
- Автозапуск с Windows, настройки в `%APPDATA%\DevSpaces\settings.json`.
- Работает с несколькими мониторами и масштабированием (панель — на основном мониторе).

## Установка

**Готовая сборка:** скачайте `DevSpaces.exe` со страницы [Releases](https://github.com/glubokovdima/DevSpaces/releases) и запустите. Установка не нужна. Значок появится в трее.

**Из исходников** (Python 3.13):

```bat
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.bat
```

Сборка EXE: `build.bat` → `dist\DevSpaces.exe`.

## Как пользоваться

- Панель справа на основном мониторе. Клик по карточке — переход на стол.
- Если панель спрятана — задержите курсор на тонкой полоске посередине правого края экрана.
- Правый клик по значку в трее — режим показа, автозапуск, выход. Левый клик — показать панель на пару секунд.
- Столы создаются, удаляются и переименовываются как обычно в Windows (Win+Tab) — панель подхватывает изменения сама.

## Ограничения

- Только Windows 11 (проверено на сборке 26300). pyvda зависит от внутренних интерфейсов Windows — после крупных обновлений Windows может понадобиться новая версия pyvda.
- На миниатюрах неактивных столов нет иконок рабочего стола; окна, которые не умеют рисовать себя (видео, игры, защищённые), могут выглядеть чёрными.
- После перезапуска Проводника перезапустите DevSpaces.
